# DN·RTLS — Промышленный UWB-трекинг. Точность 10 см.

Коммерческие RTLS-решения на чипе DW3000 (IEEE 802.15.4z).  
Антиколлизия, краны, склад, автономный транспорт, горнодобыча. Точность 10–30 см.

**Лендинг:** https://sayr777.github.io/dn-rtls/

## Аппаратная платформа

**Связка: nRF52840 (Nordic) + DW3000 (Qorvo/Decawave)**

| Параметр | Значение |
|---|---|
| UWB-трансивер | DW3000, IEEE 802.15.4z |
| Хост-контроллер | nRF52840, ARM Cortex-M4F, 64 МГц |
| Точность TWR | 10–30 см |
| Точность TDoA | 10–15 см |
| Дальность | до 80 м |
| Частота обновления | до 100 Гц |
| Безопасность | CryptoCell-310 (AES, ECC) |
| SDK | nRF Connect SDK + Zephyr RTOS |

Гибридная локация: BLE обнаруживает зону → DW3000 включается для прецизионного замера.  
Батарея метки служит в 3–5 раз дольше, чем при постоянном UWB.

## Связь с DN·Beacon

Смежный репозиторий: [sayr777/dn-beacon](https://github.com/sayr777/dn-beacon) — BLE iBeacon решения.  
Совместное применение: RTLS·Dock + DN·Yard = полная экосистема логистического терминала.
