# RTLS·Evac — Точная эвакуация с координатами

При аварии диспетчер видит точные координаты каждого работника.  
Спасатели входят с данными, не вслепую. UWB DW3000 TDoA, совместим с RTLS·Mine.

## Применение

Промышленные предприятия с требованием мгновенного управления эвакуацией: шахты, нефтехимия, производство с ограниченной видимостью (задымление, темнота).

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TDoA |
| Точность | 30–50 см |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Совместимость | RTLS·Mine (единая инфраструктура) |
| Интеграция | SCADA, пожарная сигнализация, СДПУ |

## BLE-зоны vs UWB-координаты

| | BLE-зоны | RTLS·Evac (UWB) |
|---|---|---|
| Точность | Зона 10–30 м | 30–50 см |
| Время обнаружения | До 30 с | <1 с |
| Работа при задымлении | Да | Да |
