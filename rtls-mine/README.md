# RTLS·Mine — Трекинг персонала в горных выработках

UWB-система позиционирования горняков в шахтах и тоннелях.  
TWR без синхронизации, Mesh вдоль штрека, Man-down алерт. Соответствие ФНП РД-15-08.

## Применение

Угольные и рудные шахты, горнодобывающие тоннели, подземные объекты с требованием персонального позиционирования по ФНП.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TWR Mesh |
| Точность | 30 см |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Нормативная база | ФНП РД-15-08 |
| Сигнализация | Man-down детектор (акселерометр) |

## Особенности для горных выработок

- Mesh-топология: анкеры ретранслируют сигнал вдоль штрека
- Нет требований к прямой видимости
- Метки в каске или на лямке страховочного пояса
- Батарея: 5 лет при 1 Гц обновления
