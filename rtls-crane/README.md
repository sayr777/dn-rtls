# RTLS·Crane — Позиционирование крюка крана

UWB-позиционирование крюка крана с точностью 20 см в дыму и темноте.  
3D координаты, интеграция с ПЛК Siemens, Omron, Beckhoff.

## Применение

Мостовые и козловые краны на металлургических, машиностроительных и судостроительных предприятиях.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TWR 3D (4 анкера) |
| Точность | 15–25 см |
| Частота обновления | до 50 Гц |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Интеграция | ПЛК по Modbus/TCP, Profinet, OPC UA |

## Сценарии использования

- Автоматическая парковка крюка в заданную точку
- Контроль раскачки груза
- Цифровой журнал перемещений
