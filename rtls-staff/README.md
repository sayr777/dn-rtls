# RTLS·Staff — Трекинг промышленного персонала

UWB-трекинг тысяч сотрудников на промышленном объекте.  
TDoA топология, точность 30 см, геозоны, автотабель, интеграция с 1С:КЗП.

## Применение

Нефтехимические, металлургические, горнодобывающие предприятия — крупные объекты с требованиями охраны труда и автоматического учёта рабочего времени.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TDoA |
| Точность | 30 см |
| Масштаб | тысячи меток |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Батарея метки | до 5 лет |
| Интеграция | 1С:КЗП, SAP HR, СКУД |

## Что даёт система

- Автоматический табель рабочего времени (геозоны)
- Тревожная кнопка с координатами
- История перемещений для расследования инцидентов
- Контроль доступа в опасные зоны
