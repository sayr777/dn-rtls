# RTLS·Dock — Автономный захват дока

UWB-система позиционирования автономного тягача у рампы с точностью 10 см.  
Без водителя, без оператора. Автоматический запуск ворот, рампы, конвейера.

## Применение

Логистические центры, терминалы, распределительные склады с AGV-тягачами (Evocargo и аналоги).

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TWR |
| Точность | 10 см |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Интеграция | FMS тягача, SCADA ворот/рампы |
| Пилот | 2 недели, один док |

## Цикл захвата дока

1. Тягач обнаруживает маяк дока по BLE
2. DW3000 включается для прецизионного TWR
3. Тягач заходит с точностью 10 см
4. Ворота и рампа открываются автоматически
