UWB-точность 20 см определяет, к какой ячейке тянется браслет сборщика. WMS получает подтверждение без сканирования. Ошибка комплектования → 0.

Принцип работы

01

Браслет сборщика

nRF52840 + DW3000 в браслете. Вес 60 г. Батарея 1 год. TWR с анкерами зоны — координата кисти обновляется 10 Гц.

02

Анкеры на стеллажах

По 1 анкеру каждые 8 метров на высоте 2.5 м. Стандартные крепления на вертикальные стойки стеллажей без сверления.

03

WMS сопоставление

Сервер позиционирования сравнивает координату кисти с картой ячеек. Ячейка совпадает — автоподтверждение в WMS. Не совпадает — вибросигнал на браслет.

04

Аналитика

Время на задание по зонам, топ ошибочных ячеек, производительность сборщика по часам. CSV-экспорт или REST API для BI-систем.
