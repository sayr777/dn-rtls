# RTLS·Pick — Точная комплектация на складе

UWB-система pick-by-location: точность 20 см без AoA-антенных решёток.  
DW3000, интеграция с WMS, ноль ошибок комплектования.

## Применение

Фармацевтические, автомобильные и e-commerce склады с требованием нулевой ошибки комплектования.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TWR |
| Точность | 20 см |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Интеграция | WMS, SAP EWM, 1С:Склад |
| Носимый девайс | Браслет с дисплеем или перчатка |

## RTLS·Pick vs BLE AoA

| | RTLS·Pick (UWB) | BLE AoA |
|---|---|---|
| Точность | 20 см | 30–50 см |
| Антенные решётки | Не нужны | Требуются |
| Работа в стеллажах | Да | Ограниченно |
