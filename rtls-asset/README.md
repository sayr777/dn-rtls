# RTLS·Asset — Точный учёт активов по ячейкам

UWB-трекинг активов с точностью 30 см — авто-инвентаризация без сканирования штрих-кодов.  
DW3000 TDoA, интеграция с WMS, ERP, 1С:Склад.

## Применение

Склады, производственные цеха, сервисные центры — учёт инструмента, оснастки, тары, паллет.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TDoA |
| Точность | 30 см |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Батарея метки | до 5 лет |
| Интеграция | WMS, ERP, 1С:Склад, SAP EWM |

## ROI

- Сокращение потерь инструмента и оснастки
- Авто-инвентаризация без остановки производства
- Возврат инвестиций за 2–3 месяца
