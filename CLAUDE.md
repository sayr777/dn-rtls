## Назначение репозитория

Портфолио лендингов для продажи коммерческих решений на базе UWB-модулей с чипом Decawave DW3000 (IEEE 802.15.4z).  
Все решения — промышленный RTLS (Real-Time Location System) с точностью 10–30 см.

Смежный репозиторий: `C:\MY_GIT\dn-beacon` (BLE iBeacon решения, другая платформа).

## Аппаратная платформа (справка)

| Параметр | Значение |
|---|---|
| Чипсет | Decawave DW3000 (IEEE 802.15.4z UWB) |
| Точность TWR | 10–30 см |
| Точность TDoA | 10–15 см |
| Дальность | до 80 м (промышленные условия) |
| Частота обновления | до 100 Гц |
| Каналы | 5 (6.5 ГГц) / 9 (8 ГГц) |
| Топология TWR | 3 анкера для 2D, 4 для 3D — без синхронизации |
| Топология TDoA | тысячи меток, наносекундная синхронизация анкеров |
| Шаг анкеров | 15–25 м в промышленных условиях |
| Высота монтажа | 2.5–3.5 м |

## Топологии

**TWR (Two-Way Ranging)**: метка опрашивает анкеры поочерёдно. Нет синхронизации анкеров. Ограничена масштабируемость (~100 меток).

**TDoA (Time Difference of Arrival)**: метка излучает один импульс, анкеры фиксируют время. Требуется наносекундная синхронизация часов анкеров (проводная или беспроводная по UWB). Масштаб — тысячи меток.
