# DN·RTLS — Нормативная база и стандарты

Полный реестр международных стандартов, ГОСТ, ФНП, приказов и технических регламентов, применимых к UWB RTLS системам на базе DW3000 (IEEE 802.15.4z).

## Примечание об ISO/IEC 24730-5 («ISO 13000-5»)

Этот стандарт иногда фигурирует в запросах как «ISO 13000-5». Корректное обозначение — **ISO/IEC 24730-5** (RTLS, часть 5, CSS радиоинтерфейс 2.4 ГГц). Российский аналог: ГОСТ Р ИСО/МЭК 24730-5-2014.

Стандарт **EN 13000** (мобильные краны) — отдельный документ, применим к RTLS·Crane.
