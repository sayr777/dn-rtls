# RTLS·Safe — Антиколлизия погрузчиков и AGV

UWB-система предотвращения столкновений погрузчиков, AGV и рабочих.  
Точность 10–20 см, частота 100 Гц, CAN-интеграция.

## Применение

Склады, производственные цеха, терминалы — любые зоны совместного движения транспорта и пешеходов.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Топология | TWR (Two-Way Ranging) |
| Точность | 10–20 см |
| Частота обновления | до 100 Гц |
| Чипсет | nRF52840 + DW3000 (IEEE 802.15.4z) |
| Интеграция | CAN, дискретные выходы, MQTT |

## Зоны реакции

- **Зона предупреждения** — звук + свет на метке водителя
- **Зона торможения** — автоматическое снижение скорости AGV по CAN
- **Зона стоп** — аварийная остановка
